## What's New in v1.0.0

- **The Stop Shop Release**: 46 MCP tools covering **100% of the uv CLI surface area**
- **Virtual Environment Management**: Create `.venv` with seed packages, relocatable mode, system site packages
- **Script Execution**: Run any command via `uv run` with temporary `--with` dependencies
- **Project Version & Formatting**: Bump versions, format code with Ruff
- **Pip Compatibility**: Compile, sync, freeze, install, uninstall via `uv pip`
- **Tool Management**: Install, upgrade, list, uninstall global CLI tools
- **Cache Introspection**: View cache dir, size, and prune unreachable entries
- **Publishing**: Upload distributions to PyPI with dry-run support
- **Self Management**: Update the uv binary itself
- **Concurrency Lockfile Protection**: `asyncio.Lock()` prevents `uv.lock` deadlocks
- **Absolute Path Resolution**: All project paths normalized to filesystem roots
- **ANSI-Free Streams**: Guaranteed clean subprocess output
