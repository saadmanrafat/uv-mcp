## What is UV-MCP?

UV-MCP is a **Model Context Protocol (MCP)** server that translates natural language into precise `uv` commands. It enables AI assistants — Gemini, Claude, OpenCode, and any MCP client — to autonomously manage Python environments, dependencies, and project lifecycles.

Instead of memorizing 46 different CLI flags, just say:

> *"Create a virtual environment with seed packages, install requests, and run my script."*

UV-MCP handles the rest.

---

## Key Features

<CardGrid stagger>
	<Card title="46 Typed Tools" icon="setting" >
		Every `uv` command is a structured, type-safe MCP tool with Pydantic models. From `uv add` to `uv publish`, nothing is left behind.
	</Card>
	<Card title="Self-Healing Diagnostics" icon="rocket" >
		Detects `ModuleNotFoundError`, suggests `uv add` fixes, and auto-syncs environments. Broken projects repair themselves.
	</Card>
	<Card title="Workspace Introspection" icon="magnifier" >
		Parses `[tool.uv.workspace]` members from `pyproject.toml` and emits topological dependency graphs for monorepos.
	</Card>
	<Card title="Ephemeral Tool Runner" icon="puzzle" >
		Run any CLI tool via `uv tool run` without permanent installation. Great for one-off formatters, linters, and utilities.
	</Card>
	<Card title="Concurrency Safe" icon="warning" >
		`asyncio.Lock()` serializes mutating commands to prevent `uv.lock` deadlocks during concurrent AI tool calls.
	</Card>
	<Card title="ANSI-Free Output" icon="document" >
		Guaranteed clean, parseable streams by injecting `UV_COLOR=never` and `TERM=dumb` on every subprocess.
	</Card>
</CardGrid>
