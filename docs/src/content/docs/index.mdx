## One command

```bash
claude mcp add --scope user --transport stdio uv -- uvx uv-mcp-server@latest
```

Or `codex mcp add uv -- uvx uv-mcp-server@latest`, or
`gemini extensions install https://github.com/saadmanrafat/uv-mcp`.
The only prerequisite is [uv](https://docs.astral.sh/uv/getting-started/installation/).
[All clients](/uv-mcp/guides/installation/).

## What your agent gets

| | |
|---|---|
| **Every uv command** | 46 tools named after the CLI (`uv_add`, `uv_sync`, `uv_run`, `uv_python_install`, `uv_tool_run`, `uv_pip_compile`...), `extra_args` for any flag, and `uv_command` for everything else. |
| **Structured results** | `success`, `exit_code`, `stdout`, `stderr` and an actionable `hint` on failure; parsed package, Python and tool lists. |
| **Diagnose and repair** | `uv_diagnose` checks interpreter, lockfile, `.venv` and package consistency; `uv_repair` fixes what it finds. |
| **Secure by design** | No shell, argument-injection guards, secret redaction, honest MCP annotations, read-only mode, path confinement, dry-run publishing. |
| **Runs in the right place** | Always your project's environment, never the server's own; `uv_info` shows exactly where. |
| **Context-friendly** | Compact schemas, toolsets to load only what you need, bounded output. |

## Works with

Claude Code, Codex CLI, Gemini CLI (as an extension), Claude Desktop, Cursor, VS Code, OpenCode, and any
client that speaks MCP over stdio.
